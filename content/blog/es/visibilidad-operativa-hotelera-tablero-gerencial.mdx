## Tener visibilidad significa saber dónde intervenir

Los gerentes de hotel no necesitan otro tablero lleno de actividad. Necesitan saber qué trabajo no tiene responsable, está atrasado, bloqueado, incompleto o falla repetidamente entre departamentos y turnos.

Este tablero evalúa un flujo a la vez. Utiliza un problema reciente de un huésped, una solicitud de mantenimiento, una excepción en el alistamiento de una habitación, un hallazgo de inspección o una entrega entre turnos. Califica lo que realmente ocurrió, no lo que el procedimiento dice que debería ocurrir.

Utiliza una escala sencilla:

- **0 - Ausente:** El control no existía o dependía por completo de la memoria
- **1 - Inconsistente:** El control existía en algunos pasos o para algunas personas
- **2 - Visible:** El control fue explícito y se pudo inspeccionar durante toda la entrega

## Control 1: Responsabilidad

Pregunta si cada etapa activa tenía un único rol responsable.

Evidencia de una calificación alta:

- El responsable era visible para los equipos que enviaban y recibían el trabajo
- La responsabilidad cambiaba explícitamente cuando el trabajo pasaba entre departamentos o turnos
- Existía un responsable alterno ante una ausencia o falta de respuesta
- El gerente no tenía que preguntarle al grupo quién se estaba encargando

Una bandeja compartida o un mensaje grupal puede identificar a la audiencia, pero no establece automáticamente la responsabilidad.

## Control 2: Plazo

Pregunta si la siguiente acción tenía una fecha límite o ventana de servicio observable.

Evidencia de una calificación alta:

- El tiempo se basaba en una prioridad o regla operativa definida
- La persona responsable podía ver el plazo
- El siguiente turno podía distinguir el trabajo abierto del trabajo atrasado
- El tiempo de cierre podía compararse con la expectativa acordada

Si la urgencia solo existe como una palabra dentro de un mensaje, califica este control como inconsistente o ausente.

## Control 3: Escalamiento

Pregunta si el flujo definía qué debía suceder cuando aumentaba el riesgo o se agotaba el tiempo.

Evidencia de una calificación alta:

- El escalamiento ocurría sin esperar a que un gerente recordara el asunto
- El escalamiento llegaba a un rol capaz de intervenir
- El mensaje incluía suficiente contexto para actuar
- El escalamiento no eliminaba la responsabilidad del encargado original sin una transferencia explícita

Demasiadas alertas pueden ser tan ineficaces como no tener ninguna. Califica el control según si el escalamiento produjo la respuesta operativa esperada.

## Control 4: Evidencia de cierre

Pregunta si «terminado» estaba definido y se verificaba.

Evidencia de una calificación alta:

- El estándar de cierre correspondía al riesgo del flujo
- Estaban presentes las notas, fotos, listas de verificación, inspecciones o confirmaciones requeridas
- El departamento receptor podía aceptar o rechazar el cierre
- El trabajo reabierto conservaba el contexto anterior

La evidencia debe ser proporcional. Exigir documentación excesiva para un trabajo sencillo puede reducir la adopción sin mejorar el control.

## Control 5: Visibilidad gerencial

Pregunta si el gerente podía comprender la excepción sin reconstruir el historial.

Evidencia de una calificación alta:

- El trabajo abierto se distinguía del atrasado
- Los asuntos bloqueados o escalados eran fáciles de encontrar
- El responsable actual y la siguiente acción eran visibles
- Los puntos de falla recurrentes podían revisarse a lo largo del tiempo
- El gerente podía inspeccionar la evidencia de cierre cuando fuera necesario

El objetivo no es vigilar. El objetivo es intervenir con mayor rapidez y mejor información.

## Interpreta el resultado

Suma los cinco controles para obtener una calificación de 0 a 10.

- **0-3:** La entrega depende en gran medida de que las personas recuerden, pregunten y reconstruyan
- **4-7:** Existen algunos controles, pero las excepciones aún pueden desaparecer entre equipos o turnos
- **8-10:** La entrega es ampliamente visible; concéntrate en si los controles son prácticos y se usan de manera consistente

Este es un diagnóstico, no un parámetro comparativo de la industria. Una calificación alta no demuestra que el flujo produzca el resultado esperado para el huésped o las finanzas. Demuestra que el hotel tiene suficiente control operativo para observar y mejorar lo que sucede.

## Convierte la calificación en una mejora

Elige el control con la calificación más baja y define un cambio para la siguiente semana operativa. Por ejemplo:

- Reemplaza la responsabilidad grupal por un único rol responsable
- Añade un plazo a un tipo de solicitud de alto impacto
- Define el primer paso de escalamiento
- Exige la confirmación del departamento receptor
- Crea una vista gerencial limitada al trabajo atrasado y bloqueado

Después, califica otro caso real. La mejora es más creíble cuando el mismo control funciona en varias entregas, turnos y miembros del equipo.
